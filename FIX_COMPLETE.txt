NEXT STEPS (20 minutes)
================================================================================

1. INSTALL DEPENDENCIES
   $ bun install

2. TEST LOCALLY
   $ bun run dev
   Open http://localhost:3000
   Check browser console for "Socket connected"
   Test typing indicator by opening 2 tabs

3. COMMIT CHANGES
   $ git add .
   $ git commit -m "fix: prepare for railway deployment"
   $ git push origin main

4. DEPLOY TO RAILWAY
   Go to railway.app
   New Project → Deploy from GitHub
   Select broadcast-hub repository
   Add environment variables:
     - MONGODB_URI (from MongoDB Atlas)
     - SOCKET_IO_CORS_ORIGIN (your Railway URL)
   Click Deploy

5. VERIFY IN PRODUCTION
   Load your Railway app URL
   Check socket connection in browser console
   Test typing indicators and messages

Total time: ~20-30 minutes

================================================================================
KEY ENVIRONMENT VARIABLES FOR RAILWAY
================================================================================

MONGODB_URI
  Source: MongoDB Atlas → Connect → Drivers
  Format: mongodb+srv://user:password@cluster.mongodb.net/dbname
  Required: YES

SOCKET_IO_CORS_ORIGIN
  Source: Your Railway app URL
  Format: https://[app-name].up.railway.app
  Required: YES for production
  After first deploy, get URL from Railway dashboard and redeploy

NODE_ENV
  Value: production
  Optional: Railway usually sets this automatically

PORT
  Value: 3000
  Optional: Railway usually uses this default
